雨夜规则触发 · 位置 1

不方便的地方

  • 改一个「启用 / 常驻 / 位置」都要先把整条展开，几十个字段扑面而来。
  • 条目一多，只有一个搜索框 + 14 项排序下拉 + 分页，没有目录、没有分组。
  • 没有多选：批量停用、批量改位置、批量打标签、批量移动都做不到。
  • 状态靠小灯颜色区分，没有文字，得记绿蓝灰各代表什么。
  • 备注为空时列表里显示的是关键词，看不出是哪一条。

这版怎么改

  • 左栏：视图（全部 / 常驻 / 触发 / 停用）+ 分组 + 标签，都带数量，一点就筛。
  • 中栏：一行一条的紧凑列表，勾选框做多选，状态用文字 + 圆点双编码。
  • 右栏：常驻编辑器，点哪条编辑哪条；高级设置按「触发 / 位置 / 高级」折叠，默认只看基础四项。
  • 底部：选中若干条后浮出批量条，启用 / 停用 / 设常驻 / 移动分组 / 加标签 / 删除。
